# TaskFlow Dashboard

A small task dashboard with saved filters, a weekly summary panel and a
lightweight formatting helper.

## Features

- Add, complete and filter tasks
- Saved filters per workspace
- Weekly summary of completed work
- Number and date formatting for dashboard tiles

## Run locally

```sh
bun install
bun run dev
```

Open `index.html` in the preview to see the dashboard.

## Stack

Plain HTML/CSS/JS for the shell. The formatting helpers come from
`arc137-transitive`.
